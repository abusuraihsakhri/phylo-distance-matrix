Phylogenetic Distance Matrix

Generate symmetric p-distance, Jukes–Cantor (JC69), or Kimura 2-parameter (K2P) distance matrices from aligned nucleotide FASTA.

1 · Alignment input

Up to 2 MB; input remains on this device.

Input rules: At least two unique taxa, all sequences equal length, DNA alphabet (IUPAC ambiguity and gaps accepted). Ambiguous sites and gaps are omitted per pair. Pre-align sequences before importing.

2 · Pairwise distances

No matrix computed

Model limitations: JC69 and K2P distances may be undefined for highly divergent pairs; the tool reports saturation rather than fabricating values. Outputs are evolutionary substitutions per aligned comparable site (p-distance is a proportion). No tree inference or bootstrap analysis is performed.

PHYLIP export requires taxa names of ≤10 characters without spaces. CSV supports longer names. This is a client-side scientific utility; it does not transmit sequences to a server.
